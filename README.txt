Gato Calavera POS

IMPORTANTE PARA CORRER ESTA VERSION:
1. Descomprimir el ZIP en una carpeta limpia, o reemplazar todos los archivos existentes.
2. Esta version NO usa Tailwind. Si en tu carpeta vieja queda un vite.config.ts que importa @tailwindcss/vite, debes reemplazarlo por el vite.config.ts incluido en este ZIP.
3. Ejecutar:
   npm install
   npm run dev

Si antes abriste otra version en localhost:5173, puede ser necesario borrar los datos del sitio/localStorage o usar incognito.
